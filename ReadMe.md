## 🏆 Selected Projects

### 🔧 Enterprise ERP Modernization
Full migration of a legacy monolithic ERP to native microservices on-prem. Implemented event-driven architecture via RabbitMQ, API gateway with Ocelot, containerized workloads, and GitLab CI/CD pipelines. Achieved **30% reduction in technical debt** while supporting **10,000+ daily active users**.

### 🤖 AI-Driven Business Workflow Automation
Designed and deployed a RAG platform processing **100,000+ historical records** to automate lead qualification and company registration. Integrated Gemini LLM with vector databases for semantic search and n8n for end-to-end workflow automation.

### ✅ Smart Approval System (Paperless Office)
Cross-platform (web & mobile) intelligent approval system for executive leadership with real-time push notifications and intelligent routing. Reduced approval cycles from **multiple days to under 1 hour** with full audit trails.

### 🏛️ Government e-Services Portal
Led digitization of **400+ government services** at SAIF Zone (UAE), eliminating 90% of manual paperwork and impacting **10,000+ daily users**. Includes a secure Document Management System with millions of encrypted records and a centralized KPI analytics platform.

### 💳 FinTech Cross-Border Payment Platform
Scalable, cloud-native payment platform for Dubai exchange houses via TerraPay integration. Microservices architecture with idempotent transactions, Azure Service Bus, Redis Cache, and enterprise-grade JWT/Active Directory security.

### 📚 Colwiz – Research Platform (Oxford University)
Modular JavaScript authoring suite for an Oxford University-born research platform used by Taylor & Francis, IBM, and Disney Research. Delivered a multi-source academic content scraper, WYSIWYG editor, and mathematical equation editor.
